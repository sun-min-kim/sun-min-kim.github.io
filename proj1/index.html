Project 1

Images of the Russian Empire: Colorizing the Prokudin-Gorskii Photo Collection

Single-Scale Alignment

Approach

Each photo taken by Prokudin-Gorskii is a combination of 3 grey-scale images ordered Blue, Red, and Green. In order to colorize the image, the 3 images must be merged. For the following 3 .jpg images, the grey-scale images was divided into 3, with each third representing one color-scale. Each individual image was then cropped in order to get rid of the borders. This was done because including the coloring of the borders of the image would throw off the scoring we use when aligning the 3 images. Finally, we align the 3 images together, using the blue image as a base. In order to align the green and red images to the blue one, I made use of the L2 norm, also known as the Euclidian Distance. This approach works by using a window of ±15 pixels and summing it's values in order to calculate the misalignment between the two images. The best alignment is then logged and used to align the two images together. By doing this to the green and red images (using the blue as a base), we were able to align the 3 images below pretty well. The single-scale alignment was only performed on the smaller .jpg images.

Results

Using the single scale alignment process described above, the cathedral, monastery, and tobolsk .jpg images were aligned very well. The borders does still show coloring that is off but that is a result of the original grey-scale images misalignment. The core of the image is still aligned well.

Pyramid Alignment

Approach

For larger .tif images, our single scale alignment wouldn't return accurate results over a smaller window, and using a larger window would make the process much more inefficient. In order to solve this, we can make use of an image pyramid, scaling down the image recursively and running our alignment algorithm from before, and then returning the value up while scaling up the image again. In order to do this, we repeat the same image splitting and cropping process as before. Then we make use of our pyramid function and recurse down, scaling down the image by 0.5 each time until either the x or y dimension reaches 350. At this point, we make use of our alignment algorithm from the single-scale alignment. This will give us a rough alignment score which we return up. As we recurse back up, we use both the scaled up image and double the alignment score (to account for the scale down earlier) as the base for our alignment at this new level. Eventually, our alignments will get closer as we approach the top of the stack. At each level, the window that is searched through stays at ±15.

Results

Below are the image results for the image pyramid alignment method (all .jpg and .tif images). As we can see, all of the images are aligned well except for 'emir'. For this image, because the brightness level of each grey-scale image is different, our L2 algorithm doesn't account for it perfectly. In order to improve this, using a more advanced alignment strategy could fix the issue.
